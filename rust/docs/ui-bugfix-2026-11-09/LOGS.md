# Логи: мигание при опросе

## Причина и исправление

`monitor.rs` и `windows.rs` устанавливали один и тот же `pending` как для
фонового `Get`, так и для пользовательских `SetEnabled`/`Clear`. Общий
`logs.rs` на время любого запроса отключал кнопки (opacity 0.45) и заменял
описание на «выполняется…». Повторный опрос поэтому создавал видимое мигание,
не связанное с реальным состоянием записи.

`LogView` раздельно учитывает принятый фоновый запрос и пользовательскую
операцию. Опрос не меняет описание или доступность свежего состояния; операция
отключает управление до собственного ответа. Один последовательный `Worker`
обрабатывает принятые запросы FIFO: мутация может следовать за Get, но новый
Get не ставится до ответа на мутацию. Ошибка или некорректный ответ по-прежнему
инвалидирует свежесть, сохраняет последние факты и показывает диагностику;
неизвестный результат операции автоматически не повторяется. Следующий успешный
опрос восстанавливает актуальность. Недоступный owner остаётся недоступным.

Отправители обязаны проверять `can_submit` и вызывать `submitted` только после
успешной постановки в очередь. `Model::can_submit_log` и отправитель/опрос
эмулятора в `windows.rs` интегрированы; интеграцию `monitor.rs` выполняет агент A.
В `host.rs` ошибки транспорта и несовпадающие ответы логов по-прежнему идут
через `apply(Unknown)`, а ошибки статуса отдельно инвалидируют Host freshness;
эта политика не менялась.

## Проверки и ограничения

В `tests/logs.rs` добавлены 100 повторных опросов для каждого состояния ON/OFF,
проверки стабильности текста и доступности, а также последовательности Get →
Clear/Set → потерянный ответ → отказ опроса → восстановление. Запуск Release
focused test сначала не состоялся: `cargo` отсутствует в PATH; повторный запуск
с `%USERPROFILE%\.cargo\bin`: `cargo test --release --locked --offline -p
icem-desktop --test logs` — PASS, 5/5 на Windows. Cargo сообщил future-incompatibility
warning зависимости `proc-macro-error2 v2.0.1`. Визуальная приёмка на реальном
Windows UI не выполнялась; production настройки и файлы логов не менялись.
